# Références bibliographiques

[中文](#中文) · [Français](#français)

Les articles 1 à 16 sont la bibliographie dépouillée par le groupe pour le poster
`../../docs/BA04_poster.pdf` ; la numérotation reprend celle du poster. Les deux
derniers sont des références de contexte.
